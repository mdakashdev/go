# Function
- Go-তে Function-এর return type নামের পরে লেখা হয়।

# Struct 
- Laravel-এ যেমন Model দিয়ে Employee-এর data represent করো, Go-তে Struct দিয়ে data-এর shape define করতে পারো। তবে Struct নিজে Database Model নয়। এটি Go-এর একটি custom data type।

# Create JSON Response 
- এখানে json:"id"-কে JSON Struct Tag বলা হয়।
- এটি JSON response-এ field-এর নাম id রাখবে।
